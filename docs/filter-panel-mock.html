Painel de filtros da listagem

Comparação entre o painel de hoje e quatro formas novas, no computador e no celular. Tudo é clicável: marque gerações, tipos, jogos, coleção e opções. O "Show N Pokémon" calcula com os dados reais dos 1.288 Pokémon (a coleção é de mentira, só para o exemplo). Escolher um único jogo com DLC (Sword, Shield, Scarlet ou Violet) faz aparecer o campo de DLC. Abra este arquivo direto no navegador, a partir da pasta docs/, para as imagens carregarem.

Em todas as opções novas

  • Gerações viram botões com a região embaixo; tipos viram uma grade com os ícones do app, em vez de uma lista comprida.
  • Jogos continuam em lista (são 38), agrupados por geração, com o ícone de cada jogo e uma busca.
  • "Show N Pokémon" mostra quantos vão aparecer antes de fechar o painel.
  • Os filtros aplicam na hora, como hoje. O botão "Show N Pokémon" só fecha o painel.

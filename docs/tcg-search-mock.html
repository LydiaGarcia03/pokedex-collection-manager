Observações para qualquer opção

  • A busca procura no nome da carta, no nome do set e no número. Vários termos se combinam: mcdonald 2019 encontra só a carta do McDonald's 2019.
  • Hoje o tcg-cards.json guarda só o id do set (ex.: swsh4.5sv), não o nome ("Shining Fates Shiny Vault"). Para buscar pelo nome do set é preciso incluir os nomes nos dados, seja num arquivo pequeno de sets (~221 linhas) ou num campo novo em cada carta. Isso é uma mudança de formato de dado e precisa ser decidida antes.
  • A busca reinicia quando você troca de Pokémon. No celular o campo usa fonte de 16px para o iPhone não dar zoom ao tocar.
  • Os filtros Owned/Missing/Foil só fazem sentido quando o Pokémon está selecionado (é aí que as cartas podem ser marcadas). Nas outras situações eles podem ficar escondidos.

Como representar "foil" — estilos diferentes

Aqui não muda só o ícone: cada linha é uma linguagem visual inteira (cor da caixinha, borda da carta, brilho que passa por ela, filtro, botão da carta grande e etiqueta do celular). A primeira é a de hoje, em roxo, para comparar. O brilho anima: espere um pouco em cada carta.

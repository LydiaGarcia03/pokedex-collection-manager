Teste — cartas exclusivas do Japão

Para cada Pokémon: as cartas japonesas do TCGdex que entrariam na aba TCG, os casos-limite e, recolhido no fim, o que a aba mostra hoje. Uma carta japonesa conta como a mesma arte de uma inglesa quando as duas têm o mesmo Pokémon e o mesmo ilustrador. Quando o TCGdex não tem a imagem, a página usa a do site oficial japonês (pokemon-card.com), achada pelo nome e pela coleção. A legenda diz de onde veio cada imagem. Nada foi baixado para o projeto: as imagens são carregadas direto dos dois sites.
